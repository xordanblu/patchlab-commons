# Support

## Questions and normal defects

Use GitHub Discussions for usage questions when Discussions is enabled.

Use a public issue for:

- installation problems;
- false positives without sensitive data;
- missing manifest support;
- documentation errors;
- platform compatibility problems;
- feature proposals.

Include:

- PatchLab version;
- Python version;
- operating system;
- Git version;
- the smallest safe reproduction;
- the relevant rule ID;
- redacted output.

## Security reports

Do not use a public issue for an unpatched vulnerability.

Follow [`SECURITY.md`](SECURITY.md).

## No private consulting promise

The open-source project does not guarantee private support, response time, or custom integration work.
